One letter, one answer: **A — coffee**.

The judge reads a single letter as a whole answer. Coffee is the livelier, funnier, truer pick: a jolt, a ritual, a personality — tea just politely waits.

`main.ts` writes exactly `A` to `/output/entry.txt` (UTF-8, 1 character, no trailing newline), using `MAKEFUN_OUTPUT_DIR` as-is when absolute.
